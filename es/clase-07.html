Módulo 02

Fades y Crossfades

Evitando clics y uniendo regiones de audio limpiamente.

Cuando cortas un clip de audio, a menudo interrumpes la onda en un punto que no es cero (Zero-Crossing). Esto genera un "clic" audible.

Un Fade reduce o aumenta gradualmente el volumen al inicio (Fade In) o final (Fade Out) del clip. Un Crossfade aplica un fade out al primer clip y un fade in simultáneo al segundo, cruzándolos para una transición invisible.

✂️ Atajo Útil: En Ableton, selecciona el límite entre dos clips y presiona Cmd + Option + F (Mac) o Ctrl + Alt + F (Win) para crear un crossfade rápido.
Posición del Crossfade:

Mueve el deslizador para ver cómo interactúan el volumen del Clip A (azul) y Clip B (naranja).

Módulo 03

Comping (Tomas Múltiples)

Armando la toma perfecta a partir de varias grabaciones.

¿Qué es el Comping?

Es la técnica de grabar una sección varias veces en bucle (loop) y luego seleccionar las mejores frases o palabras de cada toma para armar una única "súper toma".

En Ableton, esto se maneja mediante Take Lanes (Carriles de Toma).

Pasos para Comping:

  1. Selecciona un loop en la Vista de Arreglo.
  2. Activa el botón de grabar y haz varias tomas.
  3. Haz clic derecho en la pista y selecciona Mostrar Carriles de Toma.
  4. Subraya las mejores partes con la herramienta lápiz o flecha y presiona Enter para subirlas a la pista principal.
Módulo 04

Envolventes de Clip (Clip Envelopes)

Automatización destructiva y creativa dentro del propio clip de audio.

A diferencia de la automatización normal de pista, las envolventes de clip viven dentro del clip de audio. Si mueves o copias el clip, la envolvente viaja con él.

Pitch (Tono)

Dibuja curvas para crear efectos de tape stop, subir el tono de una tarola gradualmente, o hacer que un hi-hat tenga una melodía.

Gain (Volumen)

Perfecto para atenuar sílabas respiradas muy fuertes en una voz (de-essing manual) o crear efectos de tremolo/stutter rítmico ruteando la envolvente a la rejilla.
